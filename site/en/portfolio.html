CASE 01 AI Agent, RAG, Jev

RAG evidence selection: answer accuracy 71.7% → 93.0%, evidence sufficiency 95.4% on a fixed set

Fruition answers from uploaded documents, so I thought wrong evidence would make the whole answer untrustworthy. After seeing Jev improve request routing, I applied it to evidence selection. I then re-evaluated on a set I wrote and reviewed with my team, confirmed answer accuracy of 71.7% → 93.0% under identical conditions, and fixed what the evaluation exposed.

CASE 03 AI Agent, Compensating recovery, Audit history

Cancelling an AI task and undoing what it already saved

In a service where AI changes documents, I thought users can't hand work to AI unless cancelling is reliable. Stopping execution leaves saved document, folder, Wiki and Skill changes behind, so I built a path that reverses even committed changes in reverse order. To keep contributions other jobs made correctly, I restored pages without only the cancelled contribution.

CASE 04 PDF conversion, Data pipeline

PDF → Markdown: 96.1% body text and 99.3% table cells restored across 15 PDFs

To use papers, which mostly arrive as PDFs, as knowledge, table figures and equations had to survive conversion to Markdown first. So I traced where AI repair dropped content and split processing paths by original layout and content type.

CASE 07 Data pipeline, GPT Batch API, PySpark

Drug data pipeline: $200 estimated → $11.18 spent

Pilltip helps users understand whether they can take a medicine right now, so I thought turning difficult drug information into easy wording was the core. CASE 08 AI Agent, Sensitive data boundaries

Medication chatbot: keeping health profiles out of external AI inputs

Pilltip has to guide medication by health condition, but I thought that health information is the most sensitive personal data. So I built a chatbot that guides medication through RAG-based AI orchestration while separating symptom-based drug search from profile-based decisions. It uses the model's language understanding, while code controls how far the sensitive profile is used.
