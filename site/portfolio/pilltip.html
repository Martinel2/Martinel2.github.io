PROJECT OVERVIEW

Pilltip

의약품 정보를 쉬운 말로 안내하고, 사용자·가족의 복약 정보와 일정 관리를 돕는 개인 맞춤 AI 복약 서비스입니다.

시작 계기

부산대학교 졸업과제로 시작했습니다. 약품 정보가 여러 곳에 흩어져 있어, 지금 건강 상태에서 이 약을 먹어도 되는지 바로 확인하기 어려운 문제를 풀고자 했습니다.

팀 구성과 내 역할

MY ROLE백엔드·AI

의약품·건강기능식품 DB, 검색·자동완성, 복약 알림, 복용 위험·주의 정보 표출, 데이터 정제, AI 챗봇

  • 백엔드·AI 기능 개발의약품 관련 백엔드 기능, 복약 알림과 기록, 친구 초대와 가족 프로필 전환, 데이터 정제 파이프라인과 AI 챗봇을 구현했습니다.
  • 의약품·건강기능식품 데이터 모델링, 검색·자동완성과 복용 위험 정보 표출의약품·건강기능식품 DB를 설계하고, Elasticsearch와 Redis로 검색 자동완성, 복약 위험정보(DUR)와 주의 정보 표출 기능을 만들었습니다. LIKE 검색과 여러 JOIN 때문에 5~7초 걸리던 검색 응답을 평균 0.8초로 줄였습니다.
  • 복약 알림과 기록FCM을 활용한 복약 알림과 복약 로그 기능을 개발했습니다.
  • 친구, 가족 기능딥링크를 활용한 친구 초대와 가족 프로필 전환 기능을 개발했습니다.
  • 데이터 정제 파이프라인 구축 - 예상 $200 대비 실제 $11.18로 변환데이터 정제 파이프라인을 만들어, 서비스가 다루는 모든 의약품 정보를 친절한 구어체 설명으로 바꿨습니다.
  • RAG 기반 AI 챗봇RAG로 관련 정보를 찾고, 질문에 따라 검색·DUR 확인 등 필요한 기능을 연결하는 AI 오케스트레이션 기반 챗봇을 구현했습니다.
  • 전시 피드백을 반영한 건강기능식품 지원 확대초기 서비스는 의약품만 다뤘는데, 첫 전시 피드백 대부분이 건강기능식품도 함께 확인하고 싶다는 요청이었습니다. 공공데이터로 확보한 건강기능식품 데이터 범위에서 검색·자동완성, 복용 주의·병용 정보 표출, 복약 알림·기록, 챗봇 답변 대상까지 넓혀 전시 요청을 실제 기능으로 반영했습니다.

CASE 07 데이터 파이프라인 · GPT Batch API · PySpark

의약품 정제 파이프라인 - 예상 $200 대비 실제 $11.18로 변환

Pilltip은 사용자가 지금 이 약을 먹어도 되는지 이해해야 하는 서비스라, 어려운 의약품 정보를 이해하기 쉬운 표현으로 바꾸는 일이 핵심이라고 생각했습니다. 예산 안에서 기능을 유지하기 위해 모델 호출 수와 모델 비용을 줄여, 1GB의 의약품 데이터를 실제 $11.18로 처리했습니다. 2026년에는 같은 정제 과정을 PySpark로 재현해 단계별 효과를 측정했습니다.

CASE 08 AI Agent · 개인정보 유출 방지

복약 챗봇 - 건강 프로필을 외부 AI 입력에서 분리

Pilltip은 건강 상태에 맞춰 복약 정보를 안내해야 하지만, 그 건강 정보는 가장 민감한 개인정보라고 생각했습니다. 그래서 RAG 기반 AI 오케스트레이션으로 복약 정보를 안내하는 챗봇을 만들되, 사용자 증상에 맞는 의약품 탐색과 프로필에 따른 판단을 나눴습니다. 모델의 언어 해석 능력은 활용하면서, 민감한 프로필을 사용하는 범위는 코드로 관리했습니다.
